# Conjuntos Interativos

Aplicativo web educativo desenvolvido para a AV3 da disciplina de Modelagem e Simulação Matemática.

## Objetivo

Facilitar o aprendizado da teoria dos conjuntos por meio de exemplos visuais, diagramas de Venn e exercícios interativos.

## Conteúdos

- Conceitos básicos de conjuntos
- União
- Interseção
- Diferença
- Complemento

## Tecnologias

- HTML
- CSS
- JavaScript
